When one cutlery order contains two finishes, a warehouse may receive outer cartons that look identical. A correct retail-box code alone does not tell the receiver which variant and quantity are in each shipping carton. Before dispatch, agree on **a carton identity that can be checked against the packing list**. This article concerns the buyer's ordinary outer-case marks and contents record; it is separate from approving a consumer barcode.

The [Yumingxing cutlery RFQ guide](/en/blog/what-to-include-in-a-cutlery-rfq/) asks buyers to state the pieces per box and any carton marks. The [GS1 Logistic Label Guideline](https://ref.gs1.org/guidelines/logistic-label/) distinguishes a carton or outer-case label from a GS1 Logistic Label: the latter identifies a logistic unit with an SSCC. If a buyer's distribution system requires GS1 identifiers, obtain the exact specification and code assignment from the responsible parties. A plain text mark is not automatically a GS1 label, and no identifier is invented here.

## Make a carton-mark approval sheet

| Field | What the buyer should specify | Cross-check before dispatch |
|---|---|---|
| Order and destination | Purchase-order reference, receiving location or agreed route | Matches the shipping instruction and allocation sheet |
| Variant | Model, finish, logo and retail-pack revision | Matches the approved product and pack version |
| Pack quantity | Number of retail units per carton, or loose pieces if that is the unit | Matches the physical count and packing list unit |
| Carton sequence | Carton number and total cartons for the defined shipment or lot | No duplicate or missing number within that series |
| Human-readable mark | Exact field names, language, type size and visible carton face | Receiver can read it after normal stacking |
| Machine-readable data | Code type, owner-assigned value and verification method, **if required** | Encoded value maps to the correct case or logistic unit |
| Approval evidence | Mark proof, carton photograph, checker and version/date | Same approved version is used on packed cartons |

The buyer should first decide the unit of count. “24” could mean 24 single spoons or 24 retail sets; the mark should say which. For a mixed shipment, build one row per carton type and link each row to the packing list. If a carton deliberately contains mixed variants, label and document that exception rather than using a single-variant mark.

## Keep carton, retail unit and logistic unit distinct

A consumer pack, an outer case and a pallet may each have a different identity. Do not copy the retail-unit barcode onto every shipping level as a substitute for determining what is being identified. GS1's guideline explains that a trade-item carton code without an SSCC is not, by itself, a GS1 Logistic Label. Whether a particular case or pallet needs a GTIN, SSCC or another buyer-specific mark depends on the agreed supply-chain process; the buyer must confirm that requirement.

Before final release, compare a real packed carton with the approved mark and packing list. Photograph a readable side, check a sample of each variant and destination, and record any correction to both the label file and shipment document. This worksheet makes no claim about a Yumingxing carton size, active code allocation, warehouse acceptance or compliance with a customer's labelling rules.
