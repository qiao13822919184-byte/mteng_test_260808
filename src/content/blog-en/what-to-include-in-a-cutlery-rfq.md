A useful cutlery request for quotation (RFQ) identifies the product, quantities and conditions of the order. For Yumingxing's current catalogue, start with a model or product URL and confirm the specification rather than assuming that a photograph defines every component.

## 1. Identify the model and set composition

Send the model or reference URL. For the [Portuguese-style five-piece set](/en/products/portuguese-five-piece-flatware-set/), distinguish the dinner knife, dinner fork, dinner spoon, salad or dessert fork and dessert spoon. State whether the enquiry is for complete sets or quantities of individual pieces.

## 2. List the quantities clearly

Separate quantity per piece, per colour and per packaging configuration. Ask for the applicable MOQ for an existing model, logo application or new tooling. A quantity quoted for one route should not be assumed to apply to another.

## 3. Confirm material and finish by component

The current cutlery catalogue lists 410, 430 and 304 options; it does not assign the same grade to every component automatically. Ask for the exact material and finish of each item. Include dimensions or weight requirements where these matter to your project.

## 4. Describe logo and packaging requirements

Specify the logo location, approximate size and preferred presentation. Include a packaging reference, the number of pieces per box and any carton marks. Ask the team to confirm acceptable production artwork before preparing final files. See the [OEM/ODM project routes](/en/oem-odm-cutlery/).

## 5. Add destination and target timing

State the destination country or port and the date you need the goods. Request separate confirmation of sample timing, production lead time and shipment arrangements. An estimated production period is not an arrival guarantee.

## 6. Define the acceptance information

Ask what sample approval, inspection and product-specific documents are available. Match any material or test document to the product and relevant requirements; see the [quality and document checklist](/en/quality-compliance/).

| Include | Example of the information needed |
| --- | --- |
| Product | Catalogue model or reference URL |
| Quantity | Sets or pieces, separated by configuration |
| Specification | Material by component, dimensions and finish |
| Branding | Logo position and packaging reference |
| Logistics | Destination and required date |
| Approval | Sample route, inspection and document requirements |

Use the [enquiry brief](/en/contact/) to organise these details. It prepares an email or WhatsApp message; attach drawings and reference photos in the email application before sending.
