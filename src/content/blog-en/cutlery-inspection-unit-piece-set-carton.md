An inspection instruction that says “check 20 units” is incomplete if nobody knows whether a unit is one spoon, one retail set or one shipping carton. The choice changes what the checker opens, counts and records. Before agreeing a pre-shipment sampling plan for stainless-steel cutlery, define the **unit being inspected for each question** and the lot from which it will be selected. This is a scope decision, not an AQL recommendation.

Yumingxing's [quality guidance](https://www.mteng.ltd/en/quality-compliance/) asks buyers to agree dimensions, edges, finish, logo, set composition, packing, sampling method, tolerances and acceptance criteria against an approved sample. [ISO 2859-1:2026](https://www.iso.org/standard/2859-1) describes attribute-sampling schemes for lot-by-lot inspection. Neither source chooses a sample size or acceptance threshold for this particular order. Those parameters require a project-specific agreement and, where relevant, a qualified inspection professional.

## Name the unit in the inspection brief

| Check question | Possible inspection unit | What the buyer must define |
|---|---|---|
| Finish on a spoon | One identified spoon | Model, finish reference and applicable component lot |
| Edge or shape on a fork | One identified fork | Approved sample or drawing and observation method |
| Complete assortment | One sealed or opened retail set | Expected knife, fork and spoon counts by type |
| Retail presentation | One finished retail pack | Box revision, insert and artwork reference |
| Outer packing | One shipping carton | Units per carton, variant, mark and packing-list link |
| Material evidence | Defined component and linked batch | Which document or analysis covers which pieces |
| Result | One named unit and check point | How to record an observation and who decides disposition |

The table does not mean every project needs every check. Select the questions that matter to the order, then specify whether a failed observation is counted per component, per assembled set or per carton. For example, a set with a missing fork is a set-completeness question; a fork with an edge concern is a component question. Do not quietly convert one into the other when summarizing results.

Also define the population. “Three cartons selected” says little unless the purchase brief identifies the shipment, variant, batch or production lot they represent, and how those cartons and the pieces inside them were selected. A convenient sample taken from one open box should not be described as representative of all output without an agreed plan.

Once the unit, lot, selection method and check criteria are written, an inspector can propose the applicable sample plan and report results in the same terms. Keep any AQL level or accept/reject number out of the blog-derived worksheet until it is specified by the responsible parties. The [pre-shipment brief](/en/blog/cutlery-pre-shipment-inspection-brief/) covers the broader handoff; this card resolves the narrower ambiguity of what exactly one inspection “unit” means.
