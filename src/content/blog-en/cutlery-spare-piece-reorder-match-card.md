A hotel may need fifty more forks, not fifty new complete sets. Buying a fork that merely looks similar in a catalogue can leave a visible mismatch at the table. The replacement decision is **whether the new piece matches the approved service set**, including dimensions, balance and finish, not whether it shares a general product name.

Yumingxing's [cutlery catalogue](https://www.mteng.ltd/en/stainless-steel-cutlery/) gives model context; the [quality page](https://www.mteng.ltd/en/quality-compliance/) describes checking dimensions, weight, edges and finish against an approved sample. Neither page promises that any older piece is stocked or that a later lot will match without a comparison.

## Replacement-piece match card

| Check | Existing set reference | Proposed spare |
|---|---|---|
| Model | Original model and component ID | Supplier-confirmed component ID |
| Size | Length, bowl or tine profile, handle width | Measurements from a physical sample |
| Feel | Weight and balance in service | Side-by-side handling check |
| Appearance | Finish, handle detail and logo position | Same-light side-by-side comparison |
| Use | Fit with the venue's plate and service style | Trial at the actual table |
| Pack | Single-piece or inner-pack quantity | Order and receiving unit |
| Revision | Date and sample ID of original approval | Date and sample ID of proposed spare |

Keep one clean, identified piece from the existing set. Compare it with a physical spare sample under the same light and at the actual venue; a screen image alone can hide small changes in shape and polish. If the former model has changed, ask the supplier to name the difference and provide a new sample before approving a larger replenishment.

The buyer should also decide how to receive and count loose pieces. A supplier may quote per piece, inner pack or carton, so put the unit on the purchase order and packing list. If a perfect match is unavailable, record whether the venue will accept a controlled substitute for a specific service area. Do not silently mix variants in the same place setting.
