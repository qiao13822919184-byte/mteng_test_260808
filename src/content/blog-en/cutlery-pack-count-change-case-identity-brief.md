A buyer may approve the same knife, fork and spoon but change from a four-piece gift set to a six-piece set, or change the number of sets in an outer case. The physical cutlery has not changed, yet the order unit, case contents and warehouse identity have. Before production or label printing, treat **each changed pack level as a separate decision**.

[GS1 guidance on pack and case quantity](https://www.gs1.org/en/standards/id-keys/gtin/gtin-decision-support-tool/packcase-quantity) says a change to the number of trade items in a case, or to cases in a predefined pallet configuration, calls for a new GTIN. That is relevant when the buyer uses GS1 identifiers; it does not mean every cutlery order uses a GTIN. Yumingxing's [cutlery range](https://www.mteng.ltd/en/stainless-steel-cutlery/) offers model context, not evidence that a particular carton count has been approved.

## Freeze the quantity ladder

| Level | Buyer records | Cross-check before release |
|---|---|---|
| Piece | Exact knife, fork and spoon variants | Approved sample and component list |
| Sellable set | Count of each piece and total pieces | Box artwork, insert and purchase-order unit |
| Inner pack | Sets per inner, if used | Packing instruction and inner mark |
| Master case | Sets or inners per case | Case mark, gross weight and receiving unit |
| Pallet | Cases per predefined configuration, if relevant | Logistics instruction and any identifier impact |
| Identifier | Existing or revised trade-item and case IDs, if applicable | Owner of the GS1 decision and label proof |

Write the arithmetic explicitly. If a set contains two forks, one knife and one spoon, ten sets contain twenty forks, ten knives and ten spoons. This example is a reconciliation method, not a recommended configuration. Ask the supplier to show one packed sample at each used level and match it to the final specification. The buyer should approve both the piece-count table and the physical label proof.

A changed count can also change carton weight, space and receiving scans. Update the order, packing list and warehouse item master together. If the retailer or market has its own label rules, confirm those separately; this checklist is not a compliance ruling. Do not let an unchanged photograph stand in for the new pack configuration.
