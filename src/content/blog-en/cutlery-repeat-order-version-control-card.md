“Same as last time” is not a complete instruction for a cutlery reorder. The earlier order may have used a specific knife material, logo position, finish or retail artwork, while the current catalogue image shows only a general model. Before releasing another purchase order, compare the **last accepted order record** with the configuration now requested. This is a buyer handoff checklist, not a promise that any old tooling or material remains available.

Yumingxing's [buying process](/en/) asks for an agreed specification, sample and packing details in the order. Its [sample approval guide](/en/blog/cutlery-sample-approval-before-bulk-production/) explains how to identify the approved reference. The [component card](/en/blog/cutlery-component-specification-card/) shows why a set name alone cannot fix every knife, fork and spoon specification. A repeat purchase should point back to these controlled records, then mark what has changed.

## Copy the identity, not just the order number

| Reorder field | Last accepted record | Current request and decision |
|---|---|---|
| SKU and set composition | Model, each utensil and quantity per sellable unit | Confirm unchanged or list the affected piece. |
| Component specification | Material, dimensions and construction by knife, fork and spoon | Ask whether every prior option is still available; approve substitutions separately. |
| Appearance | Finish, handle treatment and logo artwork/position | Compare to a retained sample and controlled artwork revision. |
| Packaging | Retail unit, insert, carton count and marks | Confirm print-file version and shipping-carton configuration. |
| Acceptance basis | Approved sample ID and any agreed inspection scope | State whether the same reference applies or a new sample is needed. |
| Commercial terms | Current quantity, target date and destination | Request a fresh quote and timing confirmation rather than copying the old offer. |

Mark each row **unchanged**, **changed**, or **unconfirmed**. Even an unchanged buyer request needs supplier confirmation that the previous specification can be repeated. If a change affects one component, identify which current files supersede the old files and who approved them. Keep a short change log with the purchase order so inspection and receiving teams do not work from different revisions.

The [hotel replacement guide](/en/blog/hotel-cutlery-replacement-pattern-match/) focuses on matching new stock with existing hospitality cutlery. This card instead tracks an importer or brand's **own approved order version** for repeat production. Send the old order reference, approved sample ID, current row-by-row decisions and new quantity via the [enquiry page](/en/contact/). Do not infer current price, capacity, availability or delivery date from an earlier shipment.
