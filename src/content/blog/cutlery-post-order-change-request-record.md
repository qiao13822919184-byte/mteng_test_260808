*封面为生成的编辑示意图，不是裕明兴真实生产变更或客户订单。*

进口商可能批准餐具订单后，又要求移动 Logo、更换表面或修改零售包装。一句“请更新”并不能说明哪些刀叉勺受影响、新文件替代哪个批准版本，或价格与时间是否变化。先用**变更申请记录**写清楚，再决定是否接受新指令。本文是编辑整理的协调方法，不是合同变更通知，也不表示生产中一定可以修改。

裕明兴[采购流程](/)要求在订单中记录已批准规格、样品与检查要求；[英文 OEM/ODM 页面](/en/oem-odm-cutlery/)说明定制须按型号评估，结构改变涉及可行性审查。因而需要受控的原始版本；实际变更影响仍须按具体订单确认。

## 与已批准基线逐项比较

| 变更记录字段 | 批准前应填写 |
|---|---|
| 订单与版本 | 采购订单、受影响 SKU，以及当前批准的规格、样品或图稿版本。 |
| 拟改变内容 | 具体刀、叉、勺、Logo、表面、套装件数或包装字段；附新文件。 |
| 物料与进度 | 询问哪些单位或物料已经投入或完成，不自行推断进度。 |
| 影响评估 | 要求书面说明可行性、是否需新样、数量、费用、检查及目标时间的影响。 |
| 决策责任人 | 买卖双方联系人、决定日期，以及批准、拒绝或暂缓状态。 |
| 释放版本 | 最终替换旧版的文件，以及收到新版订单和检查指令的人员。 |

申请尚在评估时，保留原始批准版本。将提议标为**已提出**、**评估中**、**按新版批准**或**已拒绝**；只有明确批准的版本才更新执行规格。若改变了之前封样的外观或结构，应询问是否需要新样。供应商若反馈费用或时间变化，要把答复写入修订采购条款，不能默认沿用旧承诺。

[样品签核指南](/blog/cutlery-sample-approval-before-bulk-production/)帮助确认原本批准了什么；[逐件规格卡](/blog/cutlery-component-specification-card/)帮助定位受影响部件。通过[询盘页面](/contact/)发送完整申请，取得书面可行性和批准答复后再更新订单文件。
