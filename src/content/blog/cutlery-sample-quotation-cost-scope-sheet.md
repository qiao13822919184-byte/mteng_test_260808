“样品费用”四个字可能掩盖多个决定：采购方要的是现有款参照、表面对比、带品牌图稿的样品、完整盒装件套，还是这些样品的寄送？批准样品报价前，应把**交付什么**与**包含哪些准备、寄送环节**分开。这样付款决定才能对应真正要评估的样品。

裕明兴的[餐具询价指南](/en/blog/what-to-include-in-a-cutlery-rfq/)要求说明型号、部件、表面、Logo、包装、目的地与目标时间，并单独确认样品路径。采购方还应写清每件样品要回答哪一个采购问题。指南没有给出统一样品价格、快递费用、退款政策或交期；具体条件必须取得本项目的书面回复。

## 要求逐项回答样品报价范围

| 字段 | 采购方要问什么 | 为什么要问 |
|---|---|---|
| 样品身份 | 型号或图纸、刀叉勺部件及版本 | 避免付款后收到不同参照 |
| 样品形式 | 现有款参照、表面对比、带品牌样品或盒装件套 | 区分现成参照与另需准备的工作 |
| 数量 | 每种形式是单件数量还是完整套数 | 明确报价单位 |
| 准备范围 | Logo、特殊表面或包装是否包含，哪些仍待可行性确认 | 避免把普通样品当成定制样品 |
| 费用行 | 样品本身、另计的准备工作与寄送 | 付款前弄清每项费用对应内容 |
| 寄送 | 目的地、收件人、寄送方式及由谁安排、承担费用 | 避免寄送环节留空 |
| 后续订单处理 | 费用是否能抵后续大货款，以及明确的书面条件 | 避免默认抵扣或退款 |
| 决定记录 | 报价版本、供应方说明的有效期、批准人与待解决问题 | 将付款绑定到批准版本 |

这张表是**索取明确答复的工具**，并不表示所有供应方都收取每一项费用或提供抵扣。请供应方说明所选样品路径适用哪些项目。Logo、表面或包装的可行性尚未确认时，应标记“待确认”，不能当作已包含内容批准。

## 付款前对照需求与回复

把报价中的样品身份与采购方书面的索取范围逐项对照，确认数量表示单件还是整套。询问供应方将使用哪个图稿或规格版本，以及大货批准前采购方会收到什么核对资料。把预计寄件步骤和采购方需要作决定的日期分别记录；预计准备时间不是到货保证。

最后，由采购方批准人确认**具体报价版本**，包括任何书面抵扣条件及寄送责任。若部件、表面或目的地变了，付款前应取得更新后的回复。清楚的样品费用记录有助于双方推进下一步，但不意味着某个价格、交期或退款已经约定。
