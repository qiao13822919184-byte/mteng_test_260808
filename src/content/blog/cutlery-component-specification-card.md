套装名称不能代替逐件规格。“不锈钢五件套餐具”可能只给出一个笼统标题，而采购方仍需分别批准餐刀、餐叉和餐勺。比较样品或签采购订单前，先让供应方**每件餐具单独填一行**，把项目所需字段逐项写清。

裕明兴[当前英文首页](/en/)提示采购方逐件确认材质和尺寸。[葡萄牙五主件目录款](/products/portuguese-five-piece-flatware-set/)列出主餐刀、主餐叉、主餐勺、沙拉/甜品叉与甜品勺，同时展示可讨论的材质选项。目录可用作起点，但不能自动把同一牌号分配给拟订订单中的每一件。已有的[英文 RFQ 指南](/en/blog/what-to-include-in-a-cutlery-rfq/)帮助发询盘；本卡用于收到答复后记录**可与报价、样品和订单逐项对照的规格**。

## 让每件餐具都能单独核对

| 每行字段 | 批准前的采购动作 |
|---|---|
| 型号与部件名 | 标明具体刀、叉或勺及版本。 |
| 拟采用材质 | 请供应方给出该部件的牌号或构造；不要把目录中的多种选项原样抄成一个订货结论。 |
| 关键尺寸及必要时的重量 | 记录双方认可的数值、公差或参照样品。 |
| 表面与手柄细节 | 说明此部件哪些部位采用何种处理。 |
| 套装内数量 | 写明一套可售商品含此部件几件。 |
| 对应文件或样品编号 | 让证据对应具体产品、部件与目的地要求。 |
| 未决事项及批准人 | 使材质或尺寸问题保持可见。 |

此表为编辑模板，不是裕明兴现行生产数值。空白字段表示“尚未确认”，不等于“与主餐叉相同”。若餐刀由多个结构件组成，应询问各部分如何约定。不能从外观或商品名称推断材质、食品接触适用性或法规合规性。

## 下单前对齐三个版本

把供应方填好的卡片与（1）报价单、（2）实物样品或获批图纸、（3）采购订单草案逐行比较，并标出差异。只改了主餐勺的表面，不应默默改写整套规格；新样品要有新版本。请供应方说明当前有效文件及签核人。

[英文质量与文件页面](/en/quality-compliance/)提醒采购方索取与产品和目的地匹配的资料。实际需要哪些证据，取决于产品和目标市场；本文不指定某项证书或检测。逐件卡片确认后，可参考[样品签核指南](/blog/cutlery-sample-approval-before-bulk-production/)留存认可的实物参照。通过[询盘页面](/contact/)发送型号和空白卡片，请供应方填写。
