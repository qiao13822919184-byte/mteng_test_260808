采购方可能只报一个总数量，实际却计划多种餐具表面、Logo 或零售包装。“起订量是多少”的答案可能随配置变化。不能默认把不同配置的数量加总，就满足同一个门槛。应发送**配置矩阵**，请供应商确认哪些行可以合并计算。本文提供提问方式，不提供裕明兴具体 MOQ 数字。

裕明兴[英文询价清单](/en/blog/what-to-include-in-a-cutlery-rfq/)要求把单件、颜色及包装配置的数量分开，并分别询问现有款、Logo 加工与新开模的 MOQ。[现有采购流程](/)也要求在大货批准前确认可行性、报价与 MOQ。这些来源支持按路径和配置提问，并未给出适用于所有订单的统一门槛。

## 每个可销售配置单独占一行

| 配置字段 | 采购方输入 | 请供应商回答 |
|---|---|---|
| 型号与部件套装 | 型号或参考，以及准确的刀、叉、勺组合 | 此配置是否可供？ |
| 表面与材质 | 逐件的表面及材质 | 该选择是否影响起订量或打样路径？ |
| Logo | 无 Logo，或受控图稿版本与位置 | 品牌加工是否单独报价、单独计数？ |
| 包装 | 散装单件、可销售套装或品牌零售包装，并注明每单位件数 | 包装是否另有最低数量？ |
| 数量 | 此行需求的可销售单位数；预测数量明确标为预测 | 此行适用什么门槛？哪些行可合并？ |
| 审批路径 | 现有款、贴牌变化或拟新开模 | 需要哪些可行性与批准步骤？ |

例如，普通套装与相同金属餐具装入品牌盒，应列为**两行**，即使刀叉勺完全一样。应问金属件和印刷包装是否存在不同最低数量、包装由谁提供，以及某行不足门槛时如何处理。供应商未书面确认可合并范围前，不要在采购订单中直接合并数量。

[定制路径判断表](/blog/cutlery-customization-route-existing-model-private-label-new-tooling/)帮助分类；[件、套、箱核对表](/blog/flatware-pieces-sets-cartons-order-check/)防止数量单位混淆。连同目标日期和目的地，通过[询盘页面](/contact/)发送矩阵。把供应商回复的最低数量、计量单位、适用范围、有效期以及单列的开办或包装费用写在对应行。未答复的空格仍是商业待确认项，不能当作零起订量。
