*封面为生成的编辑示意图，并非裕明兴模具样、测量或工厂实拍。*

支付新餐具模具费用，不等于批准用它做出的第一把刀、叉或勺。实物可能暴露图纸上不明显的手柄形状、边缘、厚度或表面差异。买方应先指定**哪一版实物样可以放行生产**、需要核对什么、由谁签字。这与模具归属是不同的采购决定。

裕明兴的[OEM/ODM 说明](https://www.mteng.ltd/en/oem-odm-cutlery/)将新开模与现成型号、加标路线区分，并把可行性、报价、样品批准和生产安排列为不同阶段。[质量页面](https://www.mteng.ltd/en/quality-compliance/)要求以获批样品核对尺寸、重量、边缘、表面和套装组成。这些页面并不宣称某套新模具已经可用，也没有给出具体公差结果。

## 把首件样与放行决定连起来

| 记录 | 买卖双方先约定 | 留存证据 |
|---|---|---|
| 范围 | 新模具影响哪把刀、叉、勺或其他部件 | 型号与部件编号 |
| 设计基线 | 样品依据的图纸和规格版本 | 带日期的获批文件 |
| 样品身份 | 首件样版本及检查数量 | 留存实物与照片 |
| 实物核对 | 约定的尺寸、重量、边缘、表面和适配项目 | 对照书面验收准则的结果 |
| 差异 | 与设计不符之处及处理责任人 | 偏差清单和必要时的修订样 |
| 放行权限 | 买方批准人和供应方对接人 | 书面批准或拒收记录 |
| 复购参照 | 后续批次应匹配的样品和文件 | 订单中的稳定版本编号 |

检查项目应对应实际设计变更。新手柄形状可能要检查握持和托盘适配；新勺头可能要试用。先写准则再评样，不能看完样品才临时设定合格线。若需要正式性能或市场合规声明，应另行界定对应产品的证据；首件外观检查不是认证检测。

不要只凭一张看起来不错的照片就放行大货。将可识别的实物与获批文件对照，记录改正项并批准修订样。把样品编号写入采购单和检验简报，后续批次才有相同的比较基准。
