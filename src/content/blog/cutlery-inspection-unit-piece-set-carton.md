*封面是生成的编辑插画，并非裕明兴实际检验或测试结果。*

“抽查 20 个单位”这句话并不完整，因为“单位”可能是一支勺、一套零售餐具，或一箱运输外箱。定义不同，检验员打开、计数和记录的对象也不同。商定不锈钢餐具发货前抽样方案时，应先逐项明确**检查单位是什么、从哪个批次中选取**。这属于检验范围的决定，并不是 AQL 数值建议。

裕明兴的[质量说明](https://www.mteng.ltd/en/quality-compliance/)要求采购方对照已确认样品，商定尺寸、边缘、表面、标志、件套组成、包装、抽样方法、公差和验收标准。[ISO 2859-1:2026](https://www.iso.org/standard/2859-1)介绍按批进行计数抽样的方案。两项来源都不能替某笔订单确定样本量或接收界限；这些参数须按项目由责任方、必要时由合格检验人员商定。

## 在检验简报中写清单位

| 检查问题 | 可能的检验单位 | 采购方还要定义什么 |
|---|---|---|
| 餐勺表面 | 一支可识别的勺 | 型号、表面参照及适用组件批次 |
| 餐叉边缘或形状 | 一支可识别的叉 | 已确认样品或图纸及观察方法 |
| 件套完整性 | 一套封盒或打开的零售餐具 | 刀、叉、勺各自应有件数 |
| 零售陈列 | 一个成品零售包装 | 盒型版本、内托及图稿参照 |
| 运输包装 | 一只运输外箱 | 每箱数量、变体、箱唛及装箱单关联 |
| 材质证据 | 已定义组件及关联批次 | 哪份文件或分析覆盖哪些部件 |
| 检查结果 | 一种具名单位及检查点 | 如何记观察、由谁决定处置 |

这张表并不意味着每个项目都要检查所有项目。先选出订单真正关心的问题，再说明观察不符合要求时，是按组件、整套还是外箱记录。例如，整套缺少一把叉，是件套完整性问题；某把叉的边缘有疑问，是组件问题。汇总结果时不能悄悄把两种单位混为一谈。

还要明确抽取总体。“选三只外箱”若未说明这些箱代表哪笔货件、变体、批次或生产范围，以及箱和箱内餐具如何抽取，就难以解释结果。只从一只方便打开的箱中取样，不能在没有约定方案时写成代表全部产出。

单位、批次、抽取方式和检查标准写清后，检验人员才能按同一口径提出适用抽样方案并报告结果。AQL 等级和接收/拒收数字应由责任方另行确定，不能从博客表格擅自填入。[发货前检验简报](/en/blog/cutlery-pre-shipment-inspection-brief/)覆盖更广的交接工作；本文只解决“一个检验单位究竟是什么”的具体歧义。
