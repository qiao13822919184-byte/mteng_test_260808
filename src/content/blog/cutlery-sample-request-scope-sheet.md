“请寄样品”并未说明采购方需要现有款参照、表面对比、Logo 样，还是完整包装套装。索取样品前，应写清**每份样品要支持哪项决定**。本文是申请阶段的范围表，不能替代后续验收与批准记录。

裕明兴[采购流程](/)要求在大货批准前确认可行性、报价、MOQ 与打样路径；[英文询价清单](/en/blog/what-to-include-in-a-cutlery-rfq/)要求说明型号、套装构成、材质、表面、Logo 和包装。这些输入有助于供应商讨论样品类别，但不证明具体型号样品可供、费用或时间。

## 每个对比问题单独写一行

| 申请字段 | 采购方应说明 |
|---|---|
| 要作的决定 | 造型和握感、逐件材质、表面、Logo 位置或包装展示。 |
| 参照身份 | 型号或图纸、具体刀叉勺部件及拟评估版本。 |
| 样品形式 | 现有款参照、拟做品牌标识样或完整包装套装；询问可行性。 |
| 对比基础 | 将与哪份样品或已批准规格比较。 |
| 所需证据 | 根据问题确定实物、受控照片、尺寸或供应商资料。 |
| 交付与责任人 | 目的地、收件人、目标决定日期及记录结果的人。 |

例如，比较镜面与拉丝时，应问能否在**同一型号和部件**上提供两种表面；不同造型会干扰表面判断。零售包装评估则需说明目标件数和包装方式；一把散装勺子不能展示最终套装。请供应商指出无法提供的组合，不能把样品照片当成量产可行性证明。

分别确认样品可供情况、费用、时间，以及后续是否仍需生产样。样品到手后，[样品签核指南](/blog/cutlery-sample-approval-before-bulk-production/)说明如何记录获准参照；[表面对照卡](/blog/cutlery-finish-sample-comparison-card/)可帮助比较表面方案。将范围表、预计订单数量和目的地通过[询盘页面](/contact/)发送。实物或文件对照完成前，不要把“已申请”写成“已批准”。
