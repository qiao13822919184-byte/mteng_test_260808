*封面为生成的编辑示意图，不是真实证书、实验室报告或裕明兴具体 SKU 实拍。*

“请发你们的证书”对混合餐具订单来说过于笼统。某个钢材样品、旧版产品或其他目的市场的文件，未必回答本次采购的问题。应发送一张与拟订订单对应的**资料索取矩阵**。这只是沟通工具，不表示某份文件已经存在，也不作产品符合法规的结论。

裕明兴[英文品质与文件页面](/en/quality-compliance/)提示采购方索取与实际产品及目的地相关的信息；[英文询价清单](/en/blog/what-to-include-in-a-cutlery-rfq/)要求说明逐件材质和目标市场。索取文件时应同时带上这两项信息。通用标志或扫描的报告封面，单独看不能证明文件覆盖拟购套装中的刀、叉、勺。

## 先写问题，再写文件名称

| 矩阵列 | 采购方填写内容 |
|---|---|
| 订单身份 | 拟购型号、SKU、图纸或规格版本，以及具体的刀、叉或勺。 |
| 目的地与预期用途 | 需要评估的市场和用途；由当地合格人员确认相关要求。 |
| 要回答的问题 | 材质身份、某项性能声明或其他产品专属问题；分别列明。 |
| 索取的记录 | 询问供应商针对该问题有哪些声明、材质记录或独立报告。 |
| 匹配核对 | 确认记录写明或可关联相应部件、材质、样品或批次及当前版本。 |
| 缺口和决定 | 记下范围缺失或版本过旧、处理人及是否需要重新评价。 |

把**可提供**、**已索取**与**已核实适用于本订单**设为不同状态。文件即使真实，也可能覆盖不同材质或设计。Logo、涂层或手柄构造变化后，应追问既有证据是否仍适用，不能自行推断。保留完整文件、签发日期、关联的产品标识及供应商对覆盖范围的说明。

[样品签核记录](/blog/cutlery-sample-approval-before-bulk-production/)帮助识别已批准的产品版本；[英文询价清单](/en/blog/what-to-include-in-a-cutlery-rfq/)可核对订单输入。通过[询盘页面](/contact/)连同拟购逐件清单发送矩阵。目的地适用的具体规则应由当地合规专业人员判断；本文不指定通用证书或法定标准。
