酒店或餐厅可能觉得餐具样品摆在桌上很合适，却发现日常使用的清洗篮不方便装入或取出。下单前真正要回答的是现场的物理问题：**员工能否把拟采购的刀、叉、勺按实际流程放进清洗篮，再方便地取出？**应使用实物样品和现场设备核对，然后才确认组件配置。装篮适配试用不能证明耐机洗性能，也不能形成护理声明。

裕明兴的[现行餐具系列页](https://www.mteng.ltd/en/stainless-steel-cutlery/)提醒采购方逐组件确认规格与护理说明。[葡式五件套餐具](https://www.mteng.ltd/en/products/portuguese-five-piece-flatware-set/)列有主餐刀、主餐叉及两种勺，但未给出未经确认订单的具体尺寸。CATRA 介绍了[机洗耐受评价设备](https://www.catra.org/testing-equipment/cookware-saucepans/dishwasher-resistance-tester/)；那属于另一类性能评价，不证明任何拟采购餐具已通过测试。

## 建立一张实物装取核对卡

| 字段 | 采购方记录 | 实物核对 |
|---|---|---|
| 现场设备 | 清洗篮型号或照片、格位尺寸及计划装法 | 使用真实清洗篮或已明确等同的样品 |
| 餐具身份 | 每把刀、叉、勺的型号与版本 | 避免试用一款、实际购买另一款 |
| 放置 | 哪些组件共用格位、各自方向 | 观察是否需要强行弯折才能放入 |
| 取出 | 日常处理后员工如何取出 | 请目标使用者核对触及、勾挂和握持情况 |
| 件数 | 每篮、每次服务计划装入件数 | 记录试用件数，不承诺通用容量 |
| 护理问题 | 拟选表面及供应方书面说明 | 把物理适配与清洗适用性分开 |
| 确认 | 试用日期、参与者、样品编号和未决问题 | 将订单对应到具体结果与版本 |

要用完整的拟采购组合试用，不能只拿最短的勺子。刀长、叉头和勺碗与篮孔及相邻餐具的接触情况可能不同。把接触或取出困难如实记录为观察，不要因一次装篮就断定产品有缺陷。如果现场使用多种清洗篮，或计划改变装载密度，应分别核对。

这张卡**不能**回答材料、表面或装饰是否耐受现场洗涤程序、化学品或烘干条件。相关声明需要针对实际配置取得逐组件规格、护理指导和适用证据。一次快速装篮试用不能写成机洗安全认证。

把清洗篮照片、样品版本、计划件数和未解决的护理问题随核对卡一起发给供应方。刀、叉、勺或表面版本变化后，应重做受影响的项目，再批准生产套装。这样既能解决现场操作问题，也不会把它误当成需要另一类证据支持的性能结论。
